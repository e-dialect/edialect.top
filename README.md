# E-Dialect 官网

这是 [E-Dialect](https://github.com/e-dialect) 社区官网的源码仓库。

E-Dialect 是一个围绕方言、地方语言与民族语言数字化建设的开源社区。我们正在把资料整理、协同校勘、公众共建和地方语言应用中反复出现的工程问题，逐步做成可以复用的开源工具。

## 相关项目

- [E-Dialect 社区主页](https://github.com/e-dialect)
- [乡声集盒](https://github.com/e-dialect/xiangsheng-box)：面向普通用户的地方语言工具与共建平台
- [万语校坊](https://github.com/e-dialect/wanyu-proofreader)：面向资料整理团队的协同校勘平台
- [Git / GitHub 协作练习场](https://github.com/e-dialect/code-contributing-practice)：帮助新人完成第一次开源贡献

欢迎通过 Issue 和 Pull Request 改进官网内容、视觉和信息结构。
